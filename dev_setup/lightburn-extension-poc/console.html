    What does this check?

    The extension calls http://localhost:19520. It expects HTTP 200 from the API root and HTTP 401 from a request using a deliberately invalid token. A readable 401 proves that the extension can receive authentication responses.

    Passing these checks does not confirm pairing, device connection, or readiness to run a job. Use Read selected Material Library below to verify paired access.

    Pair and read your library

    Pairing requests state, project, and upload access for this POC. Project access includes camera imagery, but this extension never requests camera data.

    The secret stays in this browser's extension storage. Pairing separately in Edge and Chrome is expected.
