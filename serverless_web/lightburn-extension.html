What the integration does

  • Create a Color palette: choose one or more LightBurn settings, preview them, and assign Rasterizer swatches before saving.
  • Add to an existing Color palette: use its Import LightBurn Swatches button. Existing settings and swatch assignments are kept.
  • Create a Processing palette: choose settings for Cut, Score, Photo, Fill, Shovel, Cleaning, and 3D-Slice. Leave unused roles unassigned.
  • Load a finished project: use Load in LightBurn beside a native .lbrn2 download in Job History, review the current project, and confirm replacement.

These controls appear only while the extension is enabled. The extension does not start your laser. Review imported settings and artwork in LightBurn before engraving.

Imported palettes are snapshots, not live synchronization. The preview shows the settings applied by the importer; some source fields are retained for reference only. Creating a palette saves selected settings to your Rasterizer account. The pairing secret stays in this browser's extension storage.

Download the beta

This beta works with the staging Rasterizer website. It does not currently enable integration on the production website. You need access to staging and a Rasterizer account for Vault and Job History.

Use a desktop Chrome or Edge browser and a version of LightBurn with its REST API available. Keep LightBurn on the same computer as your browser. The tested installation path is Windows; other desktop platforms have not been verified here.

Download LightBurn Browser Extension Beta (.zip)

This is an unpacked extension, not a browser-store installer. Installation takes a few manual steps, including enabling Developer mode. Updates are manual too. No developer account or registration is needed to install this download.

The installed extension is currently named MOPA Rasterizer — LightBurn Connection POC. That is the beta's name in the browser extension list.

Install in Chrome or Edge

  1. Download and extract the ZIP. In Windows, right-click the download and choose Extract All. Put the extracted folder somewhere permanent, such as Documents\MOPA Browser Extension. Do not load it from inside the ZIP.
  2. Open your browser's extension manager. Copy the address below into the address bar of the browser you want to use.

Google Chrome

chrome://extensions

Turn on Developer mode near the top-right corner.

Microsoft Edge

edge://extensions

Turn on Developer mode in the extension manager, usually in the left sidebar.

  1. Click Load unpacked. Select the extracted mopa-lightburn-extension-beta folder that directly contains manifest.json. If you see another folder with that name inside it, open that inner folder first.
  2. Check that the extension is enabled. You should see MOPA Rasterizer — LightBurn Connection POC in the list. You can pin it using the browser's Extensions menu for easier access.
  3. Keep the folder in place. The browser reads the extension from this folder. Moving or deleting it can stop the extension working.

Repeat installation separately for each browser or browser profile you use. A work-managed browser may block unpacked extensions; in that case your administrator must allow them.

Connect and pair with LightBurn

  1. Open LightBurn and keep one instance running.
  2. In LightBurn, click Edit, then Settings. Open the Extensions tab and ensure Allow API Access from Network is checked.
  3. Select a populated Material Library if you want to import settings.
  4. Click the extension icon in your browser's Extensions menu. Its connection and diagnostics page opens.
  5. Click Check connection. A passing check confirms that the extension can reach LightBurn. It does not mean it is paired yet.
  6. Click Pair with LightBurn and approve the request in LightBurn. The request identifies MOPA Rasterizer Connection POC.
  7. Click Read selected Material Library to verify access. Then refresh the staging Vault or Job History page. You can close the diagnostics tab afterward.

Pairing is separate in Chrome and Edge. The beta requests state, project, and upload access to read settings and load projects. It does not request laser operation access.

Use it from the website

Import settings in Swatch Palette Vault

Open staging Swatch Palette Vault. Choose Import swatch palette from LightBurn for a new Color palette, Import LightBurn Swatches on an existing Color palette, or Import processing palette from LightBurn.

Read the library, select settings or assign processing roles, then click Preview import. For Color palettes, choose swatch assignments in the preview. Review the settings and any acknowledgment, then confirm the import. A completion message appears beside the action. Save pending Vault edits before importing into an existing palette.

Load a project from Job History

Open staging Job History and expand a completed job with a retained .lbrn2 download. Click Load in LightBurn. Save your current LightBurn work, review the displayed project, and confirm replacement. The beta accepts native files up to 100 MiB.

Keep one LightBurn instance open and avoid other imports or project edits during transfer. Closing the dialog does not cancel an import. If completion is unknown, inspect LightBurn before sending again.

Troubleshooting and updates

No import or Load in LightBurn buttons?

Check that you are on staging, signed in, and using the browser profile where the extension is enabled. Refresh the website after installation. Color palette append buttons appear on Color palettes; project loading appears beside .lbrn2 files, not SVG downloads.

Connection check fails or pairing is rejected?

Make sure LightBurn is open on this computer and supports its REST API. The beta uses the local API at http://localhost:19520. Reopen the extension's diagnostics page and check again. If pairing is rejected, use Pair with LightBurn and approve the new request. An HTTP 401 in the connection check is expected: that check deliberately uses an invalid token.

The library is empty or the expected setting is missing?

Select the correct Material Library in LightBurn, then read it again. The extension reads the currently selected library; it does not search all library files on your computer.

How do I update the beta?

Finish any active import first. Download and extract the latest ZIP, then replace the files inside the same permanent extension folder. Open your browser's extension manager, click Reload on the extension card, and refresh Rasterizer. Keeping the same installation normally preserves pairing; pair again if prompted. Updates are not installed automatically.

How do I remove it?

Finish any active import, then open your browser's extension manager and click Remove. The website's extension controls disappear after refresh. Ordinary file downloads still work. Removing the extension clears its local pairing data; it does not delete your saved Vault palettes.
