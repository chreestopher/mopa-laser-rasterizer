MOPA-LASER-RASTERIZER

Upload an image file, and a Lightburn Material Library file with color settings for your MOPA Fiber Laser

Download a geometry flattened, color isolated, vectorized version of the image as both an SVG and a lightburn project file with your mopa settings from your material library alreaedy applied.

Name your material settings in your lighburn material settings file with description matching the color names here, and material name containing: stainless - steel

You can control the size of each "pixel" / scaling factor with the pixel_square_mm form field

You can control how many pixels Wide or how many pixels Tall, but only one option at a time. For the other dimension option , you must put 0. The original aspect ratio will ALWAYS be respected

Please be patient, it is a slow process

All colors of lightburn layers included by default, pick the colors you want toggle on / off , when a color is toggled off it means the lightburn color layer will not be used for the engraving, and color will not be considered when finding the closest lightburn layer color, so this only exludes the color itself from the drawing, the next closest color that is not exlcluded will be used instead, but the color's settings will still be loaded into lightburn if present in your material library file.
