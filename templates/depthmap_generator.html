Directional engraving preparation

Parallax

Convert the current depthmap into Krasnow-style horizontal angle ramps, inspect exactly what will remain unengraved, and export raster or grating geometry.

Shorter rampsLonger ramps
Exact far onlyMore background

The parallax export applies Ben Krasnow's horizontal depth-edge conversion in this browser. The cutoff marks the farthest portion of the depthmap as unengraved background; strength controls the length of the angle ramps at its boundaries. For an existing depthmap, pure-white or transparent pixels always remain background, and the cutoff can include additional far-depth pixels. Set the cutoff to 0% to use only that explicit background.

Silhouette engraves every foreground cell, matching the original Krasnow process. Source Image Detail uses deterministic cell coverage to retain the uploaded image's light and dark detail while always preserving the directional edge ramps. The Parallax PNG remains an 8-bit angle map; the appearance choice affects the engraving-mask preview and SVG geometry. The SVG does not embed laser settings.

Processing settings

Choose a Processing Palette and Material. That material's assigned Cut role is selected automatically when available.

Choose the LightBurn image setting to copy to the surface bitmaps. The Processing Palette's assigned Photo role is selected automatically when available.

Configure the Photo entry's image mode, interval or DPI, speed, power, passes, and other image-processing options in LightBurn before importing the Material Library. Each sheet receives only the part of the uploaded image visible on that assembled surface. Because every sheet uses one Photo and one Cut layer, the calculated design must fit within 15 physical sheets and LightBurn's 30-layer limit.

Choose a LightBurn Line setting for the assembly guides. The selected material's assigned Score role is selected automatically when available.

Every sheet except the frontmost receives the next sheet's exact contour as a separate Score layer. Score before cutting, then align the next cut sheet to that guide during assembly. These guides are most useful for cumulative stacked reliefs.

Registration

Registration holes repeat at identical coordinates on every physical layer. Only enable them when all four positions fall inside usable material.

Workflow guidance

Natural depth groups are recommended for ordinary images. Equal depth increments preserve measured elevation relationships for topographic maps. Adaptive equal-area bands aim to place similar pixel counts in each separate band.

For maps where white represents the highest elevation, turn off source-background exclusion so the white summit remains part of the front layers.

Advanced depth boundaries

Generate a depthmap to inspect automatic layer boundaries.

The LightBurn project contains one numbered cutting layer per physical sheet. Every layer uses the same workbed and identical coordinates, and receives the selected palette setting. Optional surface engraving adds a matching Photo layer for each sheet. Optional assembly guides add a Score layer to every sheet except the frontmost. Process one sheet at a time; run Photo, then Score, then Cut when those layers are present, without moving the sheet.

Important limitation: a single photograph cannot provide measured physical depth. The model infers relative depth from visual cues and can misread reflections, transparency, shadows, abstract artwork, or unfamiliar objects. Always inspect and edit the result before using it for relief engraving. The uploaded image is processed locally; the browser downloads the AI model from Hugging Face when first used.
