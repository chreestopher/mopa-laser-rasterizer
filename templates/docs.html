MOPA Laser Rasterizer documentation

Spend less time tracing artwork, sorting color layers, and assembling Lightburn projects—and more time developing distinctive marks on metal.

Choose a photo preset for a practical starting point, or select an abstract style when you want a more expressive geometric treatment. You concentrate on developing and validating the laser settings that produce the results you want. The Rasterizer prepares color-separated vector geometry, associates matching Material Library settings, and builds the project for final review in Lightburn.

Getting started

  1. Prepare a readable JPG or PNG artwork file.
  2. Choose a saved Lightburn Material Library or upload one for the browser session.
  3. Select the material and align each editable swatch name with the appropriate Material Library setting Description.
  4. Choose the colors that contribute to the artwork.
  5. Set one processing dimension and the physical pixel size; the other dimension is calculated to preserve aspect ratio.
  6. Select a photo preset or abstract style and review its controls.
  7. Submit the job and follow its queue position and processing stages in Job History.
  8. Download the SVG or LBRN2 project, inspect every setting in Lightburn, and test it on the intended material.

Maximum processing detail uses a largest dimension of 1600 pixels and the minimum physical pixel size of 0.0625 mm, but that combination also demands more processing time and memory. Increase resolution only when the final artwork benefits from it.

How does it work?

  1. Resize and reduce: the source image is resized and mapped to the engraving colors you enabled.
  2. Build regions: neighboring same-color pixels become closed vector geometry.
  3. Apply the preset: cleanup controls refine ordinary presets, while abstract styles deliberately transform the geometry.
  4. Separate layers: color regions are coalesced and overlap is removed so each layer occupies its intended space.
  5. Attach settings: recognized swatch names are matched to descriptions in the selected Lightburn Material Library.
  6. Export: the app writes SVG geometry and an LBRN2 project for final inspection and production work in Lightburn.
