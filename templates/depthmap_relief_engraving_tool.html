Depthmap Generator for Relief Laser Engraving

Turn a single image into an editable relative grayscale depthmap, inspect a shaded relief projection, guide ambiguous artwork with source colors, and export an 8-bit or 16-bit PNG for further relief-engraving preparation.

Open the Depthmap/Relief LabRead the complete guide
This produces inferred relative depth, not measured geometry. A single flat image does not reveal hidden surfaces or reliable physical dimensions. Reflections, shadows, transparency, stylized art, and unfamiliar objects can be interpreted incorrectly. Review and edit every result before using it in a production workflow.

How the workflow moves

1. Choose

Load and inspect a supported source image locally in the browser.

2. Initialize

Run the depth model to establish the relative grayscale base.

3. Guide

Optionally use a Depth Palette so matched source colors influence depth.

4. Correct

Adjust range and curve, resize proportionally, add a far-depth border, and paint corrections.

5. Export

Compare grayscale and relief previews, then download an 8-bit or 16-bit PNG.

What the laboratory provides

Private local processing

The selected image remains in the browser. The browser downloads and runs the depth model rather than submitting the photograph as a Rasterizer server job.

Color-guided interpretation

Members can build Depth Palettes in Material Vault and assign relative depth and influence to recognized Rasterizer swatches.

Manual correction

Paint a chosen nearer or farther grayscale depth directly onto the editable output where automatic interpretation needs help.

Two previews

Inspect the actual grayscale map and a directional-light relief projection. The relief is a visualization, not the exported height data.

Controlled sizing

Width and height stay linked to the initialized aspect ratio, while optional far-depth padding extends the perimeter uniformly.

Precision choices

Use ordinary 8-bit PNG for broad compatibility or 16-bit grayscale PNG when downstream software preserves the additional tonal precision.

Desktop browser strongly recommended

The in-browser depth model requires substantial memory and CPU resources, particularly for source images larger than 500 × 500 pixels. Most phones may run out of browser memory and enter a reload loop whenever initialization is attempted. Use a desktop or laptop browser for dependable processing.

From grayscale to an engraving

The Lab exports image data, not safe laser parameters and not a ready-to-run machine command. Import the resulting PNG into software appropriate for your laser, decide how grayscale maps to power, speed, passes, or depth in that software, and test the mapping on expendable material.

Actual removal is nonlinear and depends on the laser, wavelength, focus, material, debris clearing, heat, interval, pass strategy, and control software. A lighter or darker pixel does not guarantee a proportional physical height. For the operational details and limitations, continue with the Depthmap Generator documentation.

Experimental and useful with careful review

The tool is intended to shorten the path from an image to a workable depth starting point. It does not replace sculpting judgment, measured 3D scanning, CAM preparation, material testing, or laser safety. Treat the initial result as a draft, use the grayscale and relief previews together, and correct shapes that do not describe the form you intend.
